# Filter文档说明

## 1. 功能
主要提供以下功能：
1. 用户登录验证
2. 用户注册
3. 用户登出
4. 基于`session`会话的用户身份管理
5. 错误提示反馈机制

## 2. 系统流程
1. 用户访问首页，触发 `LoginFilter`
2. 过滤器检查登录状态，未登录用户重定向至 `login.html`
3. 用户在登录页面输入登录信息并提交，触发 `LoginServlet`
4. `LoginServlet` 验证信息有效性，并根据验证结果进行相应的重定向
5. 用户成功登录后，访问 `welcome.html` 查看欢迎消息
6. 用户可选择登出，触发 `LogoutServlet` 使会话失效并重定向至首页

## 3. 各功能实现
### 1. 过滤器 (`LoginFilter`)
- **功能**：拦截所有请求，以检查用户是否已登录
- **工作流程**：
  - 验证请求路径是否需要登录状态（使用排除列表判断——不需要登录就能访问的路径("/login", "/register", "/public",)）
  - 判断用户会话中是否存在登录信息（`user` 属性）
  - 若未登录，重定向到登录页面（`httpRespone.sendRedirect(httpRequest.getContextPath()+"/login.html");`）；若已登录，允许通过（`filterChain.doFilter(servletRequest,servletResponse);`）

### 2. 登录 Servlet (`LoginServlet`)
- **功能**：处理用户的登录请求
- **工作流程**：
  - 接收用户的用户名和密码。（`User`类定义用户名和密码，`UserStore`类定义一个`HashMap`来存储用户名和密码。通过`getParameter`获取用户名和密码）
  - 进行简单的验证
    - 有该用户，则使用`UserStore.validateUser(username, password`匹配
    - 没有则重定向到注册页面
  - 登录成功后，将用户信息存入会话并重定向至欢迎页面；登录失败时返回登录页面并显示错误信息

### 3. 注册 Servlet (`RegisterServlet`)
- **功能**：处理用户的注册请求
- **工作流程**：用户提交注册信息后，直接重定向至登录页面

### 4. 登出 Servlet (`LogoutServlet`)
- **功能**：处理用户的登出请求
- **工作流程**：
  - 使当前会话失效以清除用户的登录状态（通过`session.invalidate()销毁session`）
  - 用户被重定向至首页
### 5. 公共Servlet(`PublicServlet`)

- **功能**:处理用户进入公共页面的请求
- **工作流程**：
  - 用户请求公共页面时，将请求转发给前端公共页面

### 6. 前端页面（简易）
- **首页（`index.jsp`）**
  - 显示登录与注册连接
- **登录页面 (`login.html`)**：
  - 用户名和密码输入框及提交按钮
  - 提供错误消息展示功能
- **注册页面 (`register.html`)**：
  - 用户名和密码输入框及提交按钮
- **欢迎页面 (`welcome.html`)**：
  - 显示欢迎信息和登出链接
- **公共页面 (`welcome.html`)**：
  - 显示“公共页面”

## 4. 额外功能
- 由于每次运行项目时都是没有登录的状态，这时就没有session，根据Filter工作原理会一直拦截用户请求，没法进入登录页面，为了解决此问题，我把`/index`也加入排除列表中，这样用户没有登录便可进入登录页面
